# DLMAISAIS-references
This repository holds the references (papers considered in the scoping review) and the source code to generate the
diagrams used in the research essay in context of course DLMAISAIS - AI and Society.

* `article-review-main.xlsx` - spreadsheet containing the papers considered in the scoping review
* `article-review-main-for-python.xls` - specific extract of article-review-main for the Jupyter notebook
* `classification-prompt+results.txt` - export of the paper classification conversation with ChatGPT-4o and its final results
* `IEEE-Xplore-2024-09-29.bib` - original extract of the IEEE Xplore paper sources
* `Nature-2024-09-29.bib` - original extract of the Nature paper sources
* `analysis.ipynb` - Jupyter notebook to generate the statistical diagrams used in the paper
